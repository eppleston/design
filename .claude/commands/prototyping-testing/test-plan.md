# /test-plan (prototyping-testing)

Create a comprehensive usability test plan.

## Steps
1. **Objectives** — Define research questions using `usability-test-plan` skill (via design-research).
2. **Method** — Select testing approach.
3. **Scenarios** — Craft realistic user tasks using `test-scenario` skill.
4. **Click tests** — Evaluate feature findability using `click-test-plan` skill.
5. **Accessibility** — Plan inclusive testing using `accessibility-test-plan` skill.
6. **Logistics** — Organize participants, timeline, tools, and instructions.

## Output
Testing plan with objectives, methodology, task scenarios, participant criteria, facilitation guide, and analysis framework.

Consider following up with `/evaluate` for expert review before conducting user testing.
