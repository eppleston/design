# /setup-workflow

Establish a design team workflow.

## Steps
1. **Roles** — Define roles and responsibilities using `team-workflow` skill.
2. **Cadence** — Establish collaboration cadence using `team-workflow` skill.
3. **Critique** — Define critique format using `design-critique` skill.
4. **Review gates** — Set quality checkpoints using `design-review-process` skill.
5. **Versioning** — Define file and library versioning using `version-control-strategy` skill.
6. **QA** — Establish design QA workflows using `design-qa-checklist` skill.

## Output
Workflow document with rituals calendar, critique protocols, review procedures, versioning approach, QA standards, and tool recommendations.

Consider following up with `/plan-sprint` to run the first sprint using the new workflow.
