# /handoff

Generate a complete developer handoff package.

## Steps
1. **Visual specs** — Document measurements and design tokens using `handoff-spec` skill.
2. **Interactions** — Define all states and behaviors using `handoff-spec` skill.
3. **QA checklist** — Create implementation checklist using `design-qa-checklist` skill.
4. **Review** — Verify readiness using `design-review-process` skill.
5. **Version** — Tag the design version using `version-control-strategy` skill.
6. **Package** — Compile all materials.

## Output
Visual specifications, interaction documentation, asset inventory, QA criteria, and implementation guidance.

Consider following up with `/setup-workflow` to establish ongoing QA processes.
