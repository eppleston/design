# /type-system

Create a comprehensive typography system.

## Steps
1. Establish a modular type scale using `typography-scale` skill.
2. Define hierarchy levels using `visual-hierarchy` skill.
3. Ensure adaptability across device sizes using `responsive-design` skill.
4. Create text spacing relationships using `spacing-system` skill.
5. Align content to baseline grid using `layout-grid` skill.
6. Document with implementation guidelines using `typography-scale` skill.

## Output
Scale, styles, responsive behavior, spacing, grid alignment, and usage guidelines.

Consider following up with `/design-screen` to apply the type system.
