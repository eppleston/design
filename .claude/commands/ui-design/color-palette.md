# /color-palette

Build a comprehensive color system.

## Steps
1. Generate tonal scales from input colors using `color-system` skill.
2. Map colors to semantic roles (success, error, etc.) using `color-system` skill.
3. Verify contrast ratios for all combinations using `color-system` skill.
4. Establish dark mode alternatives using `dark-mode-design` skill.
5. Define data visualization palettes using `data-visualization` skill.
6. Document the complete system with implementation guidance using `color-system` skill.

## Output
Tonal variations, semantic mappings, contrast matrices, dark mode equivalents, and usage instructions.

Consider following up with `/design-screen` to apply the palette.
