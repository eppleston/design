# /interview

Prepare for user interviews or analyze existing transcripts.

- **For Preparation**: Create a structured interview script with warm-up questions, core exploration, and wrap-up sections using the `interview-script` skill.
- **For Analysis**: Summarize interview transcripts using the `summarize-interview` skill to identify themes, notable quotes, pain points, and next steps.

Next steps: use `/synthesize` to build an affinity diagram from multiple interviews, or `/discover` to develop personas based on findings.
