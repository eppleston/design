# /build-presentation

Structure a design presentation for a specific audience.

## Steps
1. **Audience analysis** — Determine what matters to your listeners and their existing knowledge level.
2. **Story arc** — Establish narrative flow using `presentation-deck` skill.
3. **Key messages** — Narrow down to 3-5 main takeaways.
4. **Slide outline** — Map out each slide's objective and substance using `presentation-deck` skill.
5. **Rationale slides** — Incorporate decision reasoning using `design-rationale` skill.
6. **Copy review** — Polish slide language using `ux-writing` skill.

## Output
Presentation outline with slide-by-slide documentation covering purpose, content, visuals, and speaker notes.

Consider following up with `/write-rationale` for deeper exploration of reasoning sections.
