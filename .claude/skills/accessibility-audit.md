# Accessibility Audit

Conduct comprehensive accessibility audits centered on WCAG 2.2. Four principles: Perceivable, Operable, Understandable, Robust. Four-tier severity system: critical (blocks access), major, minor, enhancement (best practice). Each finding includes: location, WCAG criterion, impact assessment, remediation with code examples. Test with people with disabilities, validate across devices/browsers, examine both static and interactive states. Prioritize fixes by severity and real-world user impact.
