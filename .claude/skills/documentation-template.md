# Documentation Template

Standardize design system documentation across three types:

- **Component Documentation**: Anatomy, variants, accessibility, changelog.
- **Pattern Documentation**: Context, solutions, behavior examples, accessibility.
- **Foundation Documentation**: Purpose statements, specifications, examples, exception handling.

Standards: consistent heading hierarchy, tables for comparisons, second-person voice, critical information upfront. Operations: quarterly freshness audits, code-generated documentation where feasible, test with new team members, integrate code alongside visuals.
