# Interview Script

Create a structured user interview script for qualitative research using the funnel approach: broad context questions before specific feature questions.

## Structure

Five sections with time allocations:

1. **Introduction** (2-3 min): Welcome, consent, recording notice, session overview
2. **Warm-up** (5 min): Background, context, current behaviors — build rapport
3. **Core exploration** (20-30 min): Thematic deep-dives with follow-up probes; use JTBD techniques ("When did you last...?", "Walk me through the last time you...")
4. **Specific scenarios** (10-15 min): Task walkthroughs or experience reviews tied to your research questions
5. **Wrap-up** (5 min): Anything they want to add; what they wish we'd asked; next steps

## Key Principles

- Use open-ended questions that uncover motivations, behaviors, and mental models
- Avoid leading questions: "Was that frustrating?" → "How did you feel about that?"
- Avoid hypotheticals: "Would you use this?" → "Have you ever done this? Tell me about that."
- Probe for specifics: "How so?", "Can you tell me more?", "What happened next?"
- One question at a time — don't stack questions

## Facilitation Notes

- Stay neutral; don't react visibly to answers
- Let silence work — wait before filling pauses
- Manage tangents gently: "That's interesting — I'd like to come back to [topic]"
- Track time per section without being mechanical
