# Interview Script

Create a structured user interview script for qualitative research using the funnel approach: broad context questions before specific feature questions. Five sections: Introduction (welcome and consent), Warm-up (background and context), Core exploration (thematic deep-dives with follow-up probes), Specific scenarios (task walkthroughs or experience reviews), Wrap-up (summaries and next steps). Use open-ended questions that uncover motivations, behaviors, and mental models. Incorporate JTBD probing techniques like "When did you last...?" Avoid leading or hypothetical questions. Include facilitation notes for neutrality, tangent management, and time allocation.
