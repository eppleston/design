# Journey Map

Create comprehensive user journey maps for product design and UX analysis. Seven steps: scope clarification, stage definition (5-7 phases from awareness through post-use), detailed mapping of goals/actions/touchpoints/emotions/pain points/opportunities at each stage, emotional visualization, opportunity ranking by impact and feasibility, critical moment identification, and structured presentation. Draw from foundational UX methodology — journey maps should be persona-specific and capture both current state ("as-is") and future improvement areas.
