# Click Test Plan

Evaluate user navigation and information discovery through structured click testing. Four test types: first-click (initial behavior), click-path (complete task sequences), navigation (structural findability), five-second (information retention). Five planning elements: defined objectives, appropriate stimuli, unambiguous tasks phrased without UI guidance, measurable success criteria (accuracy and timing), participant specifications (typically 20-50 users). Benchmark: first-click success rate above 65% generally indicates good findability. Analysis: click distribution, temporal hesitation signals, correlation between confidence and accuracy. Best practices: test single tasks per screen, pre-define target areas, use authentic content, avoid instructional cues in task language, compare alternatives using identical tasks.
