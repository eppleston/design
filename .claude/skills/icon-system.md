# Icon System

24x24px base grid with five size variants (12-16px XS to 48px+ XL). Three styles: stroke, filled, duotone. Naming: "icon-[category]-[name]-[variant]". Eight categories: action, navigation, content, communication, social, status, file, device. Delivery: SVG source, sprite sheets, component wrappers, Figma library. Accessibility: each icon requires label or aria-hidden, 44x44px minimum touch targets. Maintenance: regular audits to eliminate unused icons, documented contribution workflows, version alignment with design system, test at every supported size.
