# Color System

Create systematic, accessible color palettes. Four layers: brand palette with full tonal scales, neutral grays, semantic colors (success, warning, error, info), extended palettes for data visualization. Accessibility requirements: text on backgrounds minimum 4.5:1 contrast (AA) or 7:1 (AAA), large text minimum 3:1. Generate complete tonal scales, test all foreground/background combinations, design with color blindness in mind, integrate dark mode from the start. Color relationships: tint/shade scales, complementary pairs, analogous sets.
